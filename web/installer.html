1 · Connect

Plug the FM-1 into the computer with a USB cable that carries data, switch it on, and press Connect. The browser asks to allow MIDI with system exclusive messages: allow it, that is how the FM-1 answers. Close anything else using the FM-1's MIDI port first: a DAW, or the emulator with the FM-1 selected.

Not connected.

2 · Install MONO2K

Looking for the package…

  1. Press Install and leave the cable and this page alone until it says it is done.
  2. The running firmware checks the package and stages the update loader, then the FM-1 restarts into its update mode.
  3. The loader writes MONO2K, about a minute, and the FM-1 starts again into it.
Install a package from this computer

A build of your own, or one the author sends you to test: a .fwsc made by tools/fm1/build.py. Only packages with the open FM-1 update loader are taken.

If it stops

Not foundCheck the cable carries data, nothing else holds the FM-1's MIDI port, and that you allowed MIDI. Reload the page and connect again.
Stopped writingThe FM-1 stays in its update mode until the write is complete. Replug the cable and press Install again: the page finishes the write first.
No screenSwitch it off and on. If it still shows nothing, hold OCT− while switching it on: it starts in a USB rescue mode, sound off, from which this page (and any FM-1 installer) works again.

3 · Back to the official firmware

M-VAVE's own updater takes the FM-1 back at any time. This page can too: get the official FM-1 V15 from M-VAVE and choose its unmodified FM-1.fwsc. The file is checked in your browser against V15's fingerprint and sent nowhere.

At your own risk

Installing firmware other than the FM-1's own is at your own risk; the rescue above and M-VAVE's updater are the ways back. MONO2K's patterns live in the FM-1's flash, not on the computer: they do not survive going back. MONO2K is not affiliated with M-VAVE or Elektron.

The update protocol and its code are Felucca's (fm1ota.js, fm1pkg.js, Leo Kuroshita, Hügelton Instruments), GPL-3.0, as is MONO2K. The FM-1 build stands on the open FM-1 platform: Felucca, SLOOP, Dinghy, FM-106 and CS-1.
